# Course source materials

The 22 original PDFs and PNGs supplied in the ID1206 course folder live here. They were moved without renaming or editing the files. `manifest.json` records their byte sizes and SHA-256 hashes, checked before and after the move.

The seven lecture PDFs are linked from the study answers. The two compilation PDFs and thirteen quiz screenshots are retained as supporting course material. Question references use one-based PDF page numbers, with links such as `1.3-scheduling.pdf#page=25`. Each cited page gets its own link in the app.

Include this folder when publishing or copying the app. The links use relative paths so they also work when the app is served beneath a repository path.
